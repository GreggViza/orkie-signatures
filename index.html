Email signatures

Find your name, click Copy signature, then paste it into Gmail. Takes about a minute. The "Talk to us" button is already linked — you don't need to set anything up.

How to install

  1. Click Copy signature next to your name below
  2. In Gmail: Settings (gear, top right) → See all settings
  3. Scroll to Signature, clear out anything already there
  4. Paste (Ctrl+V / Cmd+V)
  5. Set it as default for new emails and replies
  6. Save Changes at the bottom
